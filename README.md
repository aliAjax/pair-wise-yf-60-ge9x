# 无障碍人工审计协作工作台

源提示词摘要：审计员记录问题、复现步骤、影响人群和严重程度，审核员判断重复或补充证据，开发人员提交修复，复测人员关闭或重新打开问题；所有核心流程可以用键盘完成，并正确管理焦点和错误提示。

## 技术栈

SolidStart、TypeScript、Park UI、Solid Router、TanStack Query、Solid Store、Modular Forms、Zod、Solid i18n primitives。

## 本地运行

```bash
npm install
npm run dev
```

开发端口：`62025`

## 可用流程

- 创建审计问题，保存复现步骤、影响人群、证据和严重程度。
- 问题按待分诊、修复中、待复测、已关闭和重新打开流转。
- 将重复问题合并到主问题，保留来源关系和操作审计。
- 开发修复与复测结果分开记录，复测失败自动重新打开。
- 支持跳过导航、可见焦点、读屏提示、`N` 快捷键聚焦新建问题、`Ctrl+Enter` 提交。
- 数据保存在 localStorage，Park UI preset 与 Ark UI 可访问交互原语参与界面实现。

## 扫描报告对账

自动扫描报告（axe 等）与人工审计问题按「页面 + 元素定位 + 规则编号」归一化指纹配对，规则如下：

- **重复导入只更新那一条**：同一指纹的发现刷新既有问题的扫描来源（`lastSeenAt`、证据），不重复建档。
- **对上人工问题双来源保留**：人工问题填了相同定位三要素时，扫描发现关联到该问题，人工与扫描来源都保留。
- **人工结论优先**：人工定的严重程度与状态（`severitySource` / `statusSource`）永远不被扫描覆盖。
- **规则等级变化即重算**：规则目录中等级调整后 `version` 递增，扫描定级且未关闭的问题自动重算并记录事件。
- **已关闭不翻旧账**：已关闭问题只记录扫描命中痕迹，不重算、不重开。
- **并发导入先到者生效**：按报告内容哈希幂等，同一份报告同时导入只生效先到的一次（租约锁 + Web Locks）。
- **断点续传**：导入按批处理并落盘游标，中途失败保留进度，下次从断点接着做。

对账核心逻辑在 `src/lib/scan/`（纯函数，可单测）：

- `fingerprint.ts`：页面/元素定位/规则编号归一化与报告哈希。
- `reconcile.ts`：单条发现对账（`applyFinding`）与目录变化重算（`recomputeWithCatalog`）。
- `import-session.ts`：导入会话的幂等、租约互斥与断点。
- `defaults.ts`：默认规则目录与示例报告。
